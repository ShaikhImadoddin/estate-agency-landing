# Osumare — Real Estate Digital Marketing Landing Page

A responsive, Figma-accurate landing page built with semantic HTML5 and modern CSS3 for **Osumare's** real estate digital marketing services.

**Live Demo:** [https://estate-agency-landing.vercel.app](https://estate-agency-landing.vercel.app)

---

## Overview

This project translates a multi-section Figma UI specification into a production-ready static web page. Built with a mobile-first workflow, the layout scales cleanly from compact mobile screens (`375px`) to widescreen desktop displays (`1440px`) while maintaining consistent typography, spacing, and reusable component styling.

## Key Features

- **Mobile-First Responsive Design:** Uses CSS Grid, Flexbox, and targeted breakpoints (`768px` and `1024px`) for seamless adaptation across mobile, tablet, and desktop viewports.
- **Figma Design Fidelity:** Implements exact font hierarchies (`Montserrat`, `Open Sans`, `Inter`), brand color tokens (`#0078FF`, `#000C1A`, `#333333`), subtle directional gradients, and soft ambient background glows.
- **Reusable CSS Architecture:** Standardizes shared UI elements—including primary pill CTAs (`.start-btn`), form inputs (`.form-control`), and multi-column footer blocks (`.footer-col`)—to eliminate duplicate styles.
- **Complete Landing Page Flow:**
  - **Header & Hero Section:** Brand navigation with a quick-access contact CTA, headline value proposition, and hero illustration.
  - **Services & Value Proposition:** Structured service cards and real estate marketing highlights.
  - **Contact Form Section:** Two-column desktop / single-column mobile inquiry card (`Name`, `Phone`, `Email`, `Message`) framed by ambient background ellipses.
  - **Footer Section:** Translucent gradient card containing company overview, Pune office address, direct email/phone links, navigation menu, and social media links using crisp exported SVGs.

## Tech Stack

- **Markup:** Semantic HTML5
- **Styling:** CSS3 (Flexbox, CSS Grid, Media Queries, Linear Gradients)
- **Typography & Icons:** Google Fonts (`Montserrat`, `Open Sans`, `Inter`) & Figma-exported SVGs
- **Deployment:** Vercel
